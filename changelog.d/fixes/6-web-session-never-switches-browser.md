- **fix(providers):** the web-session sign-in no longer opens a different browser than the dashboard's — a Firefox dashboard gets a Firefox window, a Chrome dashboard gets Chrome. The browser build is now an OmniRoute-side dependency: when it is not cached on the host, the host downloads it itself on the first sign-in, so there is nothing to install on the operator's side, and a browser that cannot be started now fails with an explanation instead of silently falling back to Chromium. The browser family is only honoured when the dashboard is open on the OmniRoute host itself ([#6](https://github.com/neonite-rc/OmniRoute/pull/6))
