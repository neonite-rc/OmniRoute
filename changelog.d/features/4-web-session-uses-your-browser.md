- **feat(providers):** the browser sign-in opens in the browser you are actually using — the dashboard detects Firefox, Chrome, Edge or Safari from its own user agent and the server launches that family (Safari's WebKit engine, since Safari exposes no automation API). When that browser is already running with a remote-debugging endpoint, OmniRoute attaches to it instead of starting a new one, so the capture reuses the accounts you are already signed in with and no password is needed; your own tabs are left untouched. Opt out with `OMNIROUTE_WEB_SESSION_CDP=off` ([#4](https://github.com/neonite-rc/OmniRoute/pull/4))
